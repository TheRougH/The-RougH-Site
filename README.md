# Site officiel — The RougH

Site statique prêt pour **GitHub Pages**. Aucun abonnement d'hébergement n'est nécessaire avec GitHub Pages sur un dépôt public.

## Contenu déjà intégré

- page d'accueil / hero `Let Them Die`
- line-up des 5 membres
- track-list des 8 titres et durées
- bio et EPK
- crédits : enregistré à Certines, mixé à Corpeau, juillet 2026
- pochette HD, photo du groupe et livret PDF
- balises SEO, Open Graph et données structurées Schema.org
- design responsive mobile / ordinateur

## À compléter avant publication

Ouvrez **`site-config.js`** et ajoutez uniquement les liens officiels :

- e-mail de contact
- Spotify
- Deezer
- Apple Music
- YouTube Music
- YouTube
- Instagram
- Facebook
- Bluesky
- Bandcamp (si utilisé)

Les boutons dont l'URL est vide sont automatiquement masqués ou remplacés par un message discret.

## Domaine

Quand vous aurez choisi un domaine (ex. `theroughmetal.com`), remplacez `https://example.com/` dans :

- `index.html` → balise `canonical`
- `robots.txt`
- `sitemap.xml`
